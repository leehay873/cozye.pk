# Cozyé.pk — React + Vite

This is the Cozyé.pk women's winter wear website converted to a standard React.js + Vite project.

## Run locally

```bash
npm i
npm run dev
```

Then open the local URL shown by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```
